# Local-Harness 2.1.0

以 2.0.0 为基础的一次体验更新，重点是把「窗口」「模型」「插件」这三件事做得更像普通软件。

## 新增

### 窗口自适应

- 拉伸方式改为**保持比例 + 扩展视口**：放大窗口时界面等比放大并显示更多内容，不会出现黑边
- 窗口变窄（宽度不足）时自动收起侧栏，变宽自动放回；手动收起的状���不会被覆盖
- 侧栏宽度分三档（264 / 240 / 220），随窗口宽度切换
- 设置面板、插件面板、模型选择弹层按窗口比例计算尺寸，不再写死 760×600
- 记住窗口大小，下次启动恢复；最小窗口 860×560

### 模型文件夹导入

- 设置 → 模型 → 「＋ 添加文件夹…」可导入任意目录，支持多个
- 直接把文件夹（或单个 .gguf）拖进窗口也能导入
- 导入后自动扫描、自动适配；同一文件被多个目录扫到会去重
- 每个模型的适配结果单独保存，换模型换一套参数

### 模型选择

- 输入框右下角点击后弹出居中的模型列表，显示每个模型的架构、量化、大小、`适配 ngl / ctx`
- 当前模型带「当前」标记
- 列表底部可直接「添加模型文件夹」或「重新扫描」

### 明确支持范围

- 界面与文档标注：**适配 130B 及以下（含）模型**

## 修复

- 打包成 exe 后插件只加载 6 个：导出后脚本为 `.remap`，存在性判断失败，随包的 13 个插件被跳过
- 插件设置页在 exe 版里退回简化界面（同一个 `.remap` 问题）
- 语言设置不生效：I18N 在读取配置之前初始化
- 底部模型按钮文字被裁切
- 设置 → 模型页「本地 / 在线」两块没有真正折叠，现在选哪个只展开哪个
- 界面语言下拉与实际语言不一致

## 平台

仅 Windows。Linux 版已下架；受资金限制，macOS 与鸿蒙 OS 暂不适配。
