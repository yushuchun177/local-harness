# Local-Harness 使用手冊

> **本程式不包含任何 GGUF 模型權重。** 模型需要自行下載後匯入。

Local-Harness 是 llama.cpp 的圖形介面外殼，把模型載入、參數設定與多輪對話放進一個視窗，不需要輸入終端機指令。

---

## 1. 安裝與啟動

1. 下載發佈包（免安裝 zip 或單檔 exe），解壓到任意資料夾（路徑含中文也可）。
2. 雙擊 `local-harness.exe`。
3. 第一次啟動會載入模型，視窗中間顯示載入動畫，通常數秒到十幾秒。
4. 載入完成後在下方輸入框提問，按 Enter 送出。

目錄結構：

```
local-harness.exe      主程式
_internal\             執行期函式庫（請勿刪除或改名）
llama\                 llama.cpp 執行檔（llama-cli.exe 與相依 DLL）
model\                 自行放置的 .gguf 模型
chats\                 對話記錄（首次執行後產生）
config.json            介面與參數設定（首次執行後產生）
```

## 2. 準備模型

本程式不附帶模型。請自行下載 GGUF 格式模型（檔名以 `.gguf` 結尾），例如 Hugging Face、ModelScope 上的量化版本。

兩種匯入方式：

- **放入資料夾**：把 `.gguf` 複製到 `model\`，重新啟動程式後出現在上方「模型」下拉選單。
- **介面匯入**：點上方「匯入」，選擇存放模型的資料夾，程式會記住該路徑。

注意事項：

- 分片模型只需放入第一片（`xxx-00001-of-00002.gguf`），其餘分片放在同一資料夾。
- 程式會自動忽略 mmproj、視覺投影、向量化與重排模型，以及小於 20MB 的檔案。
- 模型權重由各自發佈方授權（例如 Qwen 系列為 Apache-2.0），請遵守對應授權。

依記憶體選擇模型：

| 模型規模 | 檔案大小（參考） | 建議記憶體 |
| --- | --- | --- |
| 0.4B – 1B | 300MB – 900MB | 4GB 以上 |
| 1.5B – 2B | 1GB – 2GB | 8GB |
| 3B – 4B | 2GB – 3GB | 16GB |

## 3. 介面說明

- **上方工具列**：模型下拉選單、「匯入」按鈕、參數（溫度 / 上下文 / 回覆上限）、思考模式開關、「關於」「設定」、深淺主題切換。
- **左側欄**：對話清單。滑鼠移上去顯示刪除按鈕，按右鍵可重新命名或刪除。
- **中間**：對話區，回答逐字串流輸出。
- **底部**：輸入框與「送出」按鈕；產生過程中按鈕變為「停止」。
- **狀態列**：左側顯示目前模型、上下文用量與模型原生上限；右側顯示本對話的 token 佔比。

## 4. 參數說明

| 參數 | 範圍 | 說明 |
| --- | --- | --- |
| 溫度 | 0 – 2 | 越低越穩定保守，越高越發散。寫程式 0.2–0.6，日常問答 0.7，創意寫作 0.9–1.2 |
| 上下文 | 512 – 模型原生上限 | 一次對話保留的 token 數。滑桿上限由模型本身決定，狀態列顯示「原生 xxxx」 |
| 回覆上限 | 64 – 8192 | 單次回答最多產生的 token 數。回答被截斷就調大 |
| 思考模式 | 開 / 關 | 支援思考的模型（如 Qwen3）先思考再回答；思考過程不會顯示在回答中 |

參數可直接在數字框輸入，也可拖動滑桿，修改立即生效並儲存到 `config.json`。

## 5. 上下文壓縮

長對話會超出上下文視窗。啟用自動壓縮後，當對話 token 數達到觸發門檻，程式會在下一輪提問前把較早的歷史壓縮成摘要，只保留最近數輪原話。

- 位置：上方「設定」→「上下文壓縮」。
- 觸發門檻以 1024 token 為一階，可選 **1024 / 2048 / 3072 / 4096**，預設 **2048**。
- 可指定保留最近幾輪原話（預設 4 輪）。
- 壓縮會暫時啟動一個模型行程做摘要，需要數秒，期間無法送出問題。
- 不想自動壓縮可在設定中關閉，此時上下文用滿後請自行「新對話」。

## 6. 快速鍵

| 按鍵 | 功能 |
| --- | --- |
| Enter | 送出 |
| Shift + Enter | 換行 |
| Ctrl + Enter | 送出 |
| Esc | 停止產生 |
| Ctrl + L | 清空輸入框 |

## 7. 資料與備份

- 對話儲存在 `chats\`，一個對話一個 `.json`；刪除檔案即刪除對話。
- 介面、參數與已匯入的模型資料夾儲存在 `config.json`；刪除後回復預設值。
- 程式不連網、不需要帳號，對話內容不會上傳。
- 換電腦：把整個程式資料夾複製過去即可（含 `model\`）。

## 8. 常見問題

**雙擊後一閃就結束**
多半是 `_internal\` 或 `llama\` 被移動或被防毒軟體隔離，重新解壓一份完整發佈包。

**提示「還沒有模型檔案」**
`model\` 是空的。放入 `.gguf`，或用「匯入」選擇資料夾，然後重新啟動。

**下拉選單沒有我的模型**
確認是 `.gguf`、大於 20MB、不是 mmproj 或向量模型；分片模型只放第一片。

**回答很慢**
換較小的模型；在「設定」把執行緒數設為 CPU 核心數；筆電接上電源並關閉省電模式。

**回答被截斷**
把「回覆上限」調大（例如 2048）。

**聊久了變慢或提示上下文不足**
程式預設開啟自動壓縮，可在「設定」確認門檻；也可新建對話重新開始。

**模型名稱顯示為英文或帶量化後綴**
程式直接讀取 GGUF 內的模型名稱，顯示成 `Qwen3 0.6B · Q8_0` 這類形式，屬正常。

## 9. 測試環境

本版本在以下環境完成驗證：Windows 11（64 位元）、Intel Core i5-4590（4 核 4 執行緒，支援 AVX2）、16GB 記憶體，純 CPU 推論，未使用獨立顯示卡。

實測生成速度（4 執行緒、上下文 2048）：SmolLM2-360M 約 42 t/s，Llama-3.2-1B 約 21 t/s，Qwen3-0.6B 約 15 t/s，Qwen2.5-1.5B / Qwen3-1.7B 約 7 t/s，Qwen2.5-3B 約 6 t/s。完整硬體與模型資料見倉庫 README 的「測試環境」一節。
