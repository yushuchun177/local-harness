# Local-Harness 使用手册

> **本程序不包含任何 GGUF 模型权重。** 模型需要自行下载后导入。

Local-Harness 是 llama.cpp 的图形界面外壳，把模型加载、参数配置和多轮对话放进一个窗口，不需要敲命令行。

---

## 1. 安装与启动

1. 下载发布包（绿色版 zip 或单文件 exe），解压到任意目录（路径含中文也可以）。
2. 双击 `local-harness.exe`。
3. 首次启动会加载模型，界面中间显示加载动画，通常几秒到十几秒。
4. 加载完成后即可在底部输入框提问，按 Enter 发送。

绿色版目录结构：

```
local-harness.exe      主程序
_internal\             运行库（不要删除或改名）
llama\                 llama.cpp 运行文件（llama-cli.exe 及依赖 DLL）
model\                 自行放置的 .gguf 模型
chats\                 对话记录（首次运行后生成）
config.json            界面与参数设置（首次运行后生成）
```

## 2. 准备模型

本程序不附带模型。请自行下载 GGUF 格式的模型文件（文件名以 `.gguf` 结尾），来源例如 Hugging Face、ModelScope 上的量化版本。

两种导入方式：

- **放进目录**：把 `.gguf` 文件复制到程序目录下的 `model\` 文件夹，重启程序后出现在顶部「模型」下拉框中。
- **界面导入**：点击顶部「导入」，选择一个存放模型的文件夹，程序会记住该路径。

注意事项：

- 分片模型只需放入第一片（`xxx-00001-of-00002.gguf`），其余分片放在同一目录。
- 程序会自动忽略 mmproj、视觉投影、向量化与重排模型，以及小于 20MB 的文件。
- 模型权重由各自发布方授权（例如 Qwen 系列为 Apache-2.0），请遵守对应许可。

按内存挑选模型：

| 模型规模 | 文件大小（参考） | 建议内存 |
| --- | --- | --- |
| 0.4B – 1B | 300MB – 900MB | 4GB 起 |
| 1.5B – 2B | 1GB – 2GB | 8GB |
| 3B – 4B | 2GB – 3GB | 16GB |

## 3. 界面说明

- **顶部栏**：模型下拉框、「导入」按钮、参数（温度 / 上下文 / 回复上限）、思考模式开关、「关于」「设置」、深浅主题切换。
- **左侧栏**：会话列表。悬停显示删除按钮，右键可重命名或删除。
- **中间**：对话区。回答逐字流式输出。
- **底部**：输入框与「发送」按钮；生成过程中按钮变为「停止 ■」。
- **状态栏**：左侧显示当前模型、上下文占用与模型原生上限；右侧显示当前会话的 token 占比。

## 4. 参数说明

| 参数 | 范围 | 说明 |
| --- | --- | --- |
| 温度 | 0 – 2 | 越低越稳定保守，越高越发散。写代码 0.2–0.6，日常问答 0.7，创意写作 0.9–1.2 |
| 上下文 | 512 – 模型原生上限 | 一次对话能保留的 token 数。滑块上限由模型自身决定，状态栏显示「原生 xxxx」 |
| 回复上限 | 64 – 8192 | 单次回答最多生成的 token 数。回答被截断就调大 |
| 思考模式 | 开 / 关 | 支持思考的模型（如 Qwen3）先思考再回答；思考过程不显示在回答里 |

参数可以直接在数字框输入，也可以拖动滑块，修改立即生效，并自动保存到 `config.json`。

## 5. 上下文压缩

长对话会超出上下文窗口。启用自动压缩后，当对话 token 数达到触发阈值，程序会在下一轮提问前把较早的历史压缩成一段摘要，只保留最近若干轮原话。

- 打开方式：顶部「设置」→「上下文压缩」。
- 触发阈值按 1024 token 一档，可选 **1024 / 2048 / 3072 / 4096**，默认 **2048**。
- 压缩时可指定保留最近几轮原话（默认 4 轮）。
- 压缩会临时启动一个模型进程做总结，需要几秒；期间不能发送新问题。
- 不想要自动压缩可以在设置里关闭，此时对话上下文用满后需要手动「新对话」。

## 6. 快捷键

| 按键 | 功能 |
| --- | --- |
| Enter | 发送 |
| Shift + Enter | 换行 |
| Ctrl + Enter | 发送 |
| Esc | 停止生成 |
| Ctrl + L | 清空输入框 |

## 7. 数据与备份

- 对话保存在 `chats\` 目录，一个会话一个 `.json` 文件；删除文件即删除会话。
- 界面、参数、已导入的模型目录保存在 `config.json`；删除后恢复默认设置。
- 程序不联网、不需要账号，对话内容不会上传。
- 换电脑：把整个程序目录拷走即可（模型在 `model\` 里就一并带走）。

## 8. 常见问题

**双击后一闪就退出**
多半是 `_internal\` 或 `llama\` 被移动、被安全软件隔离。重新解压一份完整发布包。

**提示「还没有模型文件」**
`model\` 为空。把 `.gguf` 放进去，或用顶部「导入」选择模型文件夹，然后重启程序。

**模型下拉框里没有我的模型**
确认是 `.gguf` 格式、体积大于 20MB、不是 mmproj 或向量模型；分片模型只放第一片。

**回答很慢**
换更小的模型；在「设置」里把线程数设为 CPU 核心数；笔记本接通电源、关闭省电模式。

**回答被截断**
把「回复上限」调大（如 2048）。

**聊久了变慢或提示上下文不足**
程序默认开启自动压缩，可在「设置」中确认阈值；也可以新建会话重新开始。

**模型名显示成英文或带量化后缀**
程序直接读取 GGUF 内的模型名称，显示为 `Qwen3 0.6B · Q8_0` 这类形式，属正常。

## 9. 测试环境

本版本在以下环境完成验证：Windows 11（64 位）、Intel Core i5-4590（4 核 4 线程，支持 AVX2）、16GB 内存，纯 CPU 推理，未使用独立显卡。

实测生成速度（4 线程、上下文 2048）：SmolLM2-360M 约 42 t/s，Llama-3.2-1B 约 21 t/s，Qwen3-0.6B 约 15 t/s，Qwen2.5-1.5B / Qwen3-1.7B 约 7 t/s，Qwen2.5-3B 约 6 t/s。完整硬件与模型数据见仓库 README 的「测试环境」一节。
