# Local-Harness ユーザーマニュアル

> **本プログラムに GGUF モデルの重みは同梱されていません。** モデルはご自身でダウンロードして読み込ませてください。

Local-Harness は llama.cpp のグラフィカルなハーネスです。モデルの読み込み、パラメータ設定、複数ターンの対話を 1 つのウィンドウにまとめ、コマンドライン操作を不要にします。

---

## 1. インストールと起動

1. リリース（ポータブル zip または単一 exe）をダウンロードし、任意のフォルダに解凍します（日本語や中国語を含むパスでも可）。
2. `local-harness.exe` をダブルクリックします。
3. 初回起動時にモデルを読み込みます。画面中央に読み込み表示が出て、数秒から十数秒かかります。
4. 読み込み完了後、下部の入力欄に質問を入力し Enter で送信します。

フォルダ構成：

```
local-harness.exe      本体
_internal\             ランタイム（削除・改名しないでください）
llama\                 llama.cpp 実行ファイル（llama-cli.exe と依存 DLL）
model\                 ご自身の .gguf モデル
chats\                 対話履歴（初回起動後に生成）
config.json            画面とパラメータの設定（初回起動後に生成）
```

## 2. モデルの準備

モデルは同梱されていません。GGUF 形式（拡張子 `.gguf`）のモデルを、Hugging Face や ModelScope などからご自身でダウンロードしてください。

読み込み方法は 2 通り：

- **フォルダに置く**：`.gguf` を `model\` にコピーし、プログラムを再起動すると上部のモデル一覧に表示されます。
- **画面から取り込む**：上部の「インポート」を押し、モデルの入ったフォルダを選択します。パスは記憶されます。

注意：

- 分割モデルは 1 つ目のファイル（`xxx-00001-of-00002.gguf`）だけで構いません。残りは同じフォルダに置いてください。
- mmproj、視覚プロジェクタ、埋め込み・リランカーモデル、20MB 未満のファイルは自動的に除外されます。
- モデルの重みは各配布元のライセンスに従います（Qwen 系は Apache-2.0 など）。

メモリ別の目安：

| モデル規模 | ファイルサイズ（目安） | 推奨メモリ |
| --- | --- | --- |
| 0.4B – 1B | 300MB – 900MB | 4GB 以上 |
| 1.5B – 2B | 1GB – 2GB | 8GB |
| 3B – 4B | 2GB – 3GB | 16GB |

## 3. 画面の説明

- **上部バー**：モデル選択、インポート、パラメータ（温度 / コンテキスト / 応答上限）、思考モード、「情報」「設定」、テーマ切替。
- **左側**：対話一覧。ホバーで削除ボタン、右クリックで名前変更・削除。
- **中央**：対話エリア。応答はトークン単位でストリーミング表示されます。
- **下部**：入力欄と送信ボタン。生成中は「停止」に変わります。
- **ステータスバー**：左に現在のモデル、コンテキスト使用量とモデル本来の上限、右に対話のトークン比率。

## 4. パラメータ

| パラメータ | 範囲 | 説明 |
| --- | --- | --- |
| 温度 | 0 – 2 | 低いほど安定、高いほど多様。コード 0.2–0.6、一般質問 0.7、文章作成 0.9–1.2 |
| コンテキスト | 512 – モデル本来の上限 | 1 つの対話で保持するトークン数。スライダーの上限はモデル側の値で、ステータスバーに「原生 xxxx」と表示されます |
| 応答上限 | 64 – 8192 | 1 回の応答で生成する最大トークン数。途中で切れる場合は増やしてください |
| 思考モード | オン / オフ | 思考対応モデル（Qwen3 など）で、考える過程を経てから回答します。思考内容は応答に表示されません |

数値は直接入力もスライダーでも変更でき、即時反映され `config.json` に保存されます。

## 5. コンテキスト圧縮

長い対話はいずれコンテキスト上限に達します。自動圧縮を有効にすると、対話のトークン数がしきい値に達した時点で、次の質問の前に古い履歴を要約 1 件にまとめ、直近の数ターンだけ原文で残します。

- 場所：上部「設定」→「コンテキスト圧縮」。
- しきい値は 1024 トークン刻みで **1024 / 2048 / 3072 / 4096** から選択、既定値は **2048**。
- 原文で残すターン数も指定できます（既定 4 ターン）。
- 圧縮時は一時的にモデルプロセスを起動するため数秒かかり、その間は送信できません。
- 自動圧縮を使わない場合は設定でオフにし、上限に達したら「新しい対話」で開始してください。

## 6. ショートカット

| キー | 動作 |
| --- | --- |
| Enter | 送信 |
| Shift + Enter | 改行 |
| Ctrl + Enter | 送信 |
| Esc | 生成を停止 |
| Ctrl + L | 入力欄をクリア |

## 7. データとバックアップ

- 対話は `chats\` に 1 対話 1 つの `.json` として保存されます。ファイルを削除すると対話も削除されます。
- 画面状態・パラメータ・取り込んだモデルのフォルダは `config.json` に保存されます。削除すると初期設定に戻ります。
- 本プログラムはネットワークに接続せず、アカウントも不要です。対話内容は送信されません。
- 別の PC へ移す場合は、プログラムフォルダごとコピーしてください（`model\` も含めて）。

## 8. よくある質問

**ダブルクリックしても一瞬で終了する**
`_internal\` または `llama\` が移動された、もしくはセキュリティソフトに隔離された可能性があります。リリースを解凍し直してください。

**「モデルファイルがありません」と表示される**
`model\` が空です。`.gguf` を置くか「インポート」でフォルダを指定し、再起動してください。

**一覧にモデルが出ない**
`.gguf` 形式で 20MB 以上、mmproj や埋め込みモデルでないことを確認してください。分割モデルは 1 つ目のファイルのみ置きます。

**応答が遅い**
より小さいモデルに変更する、「設定」でスレッド数を CPU コア数にする、ノート PC は電源に接続し省電力モードを解除する。

**応答が途中で切れる**
「応答上限」を増やしてください（例：2048）。

**長く使うと遅い、コンテキスト不足の表示が出る**
自動圧縮は既定で有効です。「設定」でしきい値を確認するか、新しい対話を開始してください。

**モデル名が「Qwen3 0.6B · Q8_0」のように表示される**
GGUF 内のメタデータから名前と量子化を読み出しているためで、正常な動作です。
